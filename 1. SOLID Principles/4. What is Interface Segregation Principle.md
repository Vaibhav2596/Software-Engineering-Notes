## What is Interface Segregation Principle ?

1. The Interface Segregation Principle (ISP) states that a class should not be forced to implement interfaces that it does not use.
2. It is better to have multiple smaller interfaces than larger interfaces.

```csharp
public interface IVehicle
{
    void Drive();

    void Fly();
}
```

```csharp
public class FlyingCar : IVehicle
{
    public void Drive()
    {
        Console.Write("Drive Car");
    }

    public void Fly()
    {
        Console.Write("Fly Car");
    }
}

```

```csharp
public class Car : IVehicle
{
    public void Drive()
    {
        Console.Write("Drive Car");
    }

    public void Fly()
    {
        throw new NotImplementedException();
    }
}

```

### It is better to have multiple smaller interfaces than larger interfaces.

```csharp
public interface IDrive
{
    void Drive();
}

publice interface IFly
{
    void Fly();
}
```

```csharp
public class Car : IDrive{
    public void Drive()
    {
        Console.Write("Drive Car");
    }
}

public class FlyingCar : IDrive, IFly
{
    public void Drive()
    {
        Console.Write("Drive Car");
    }

    public void Fly()
    {
        Console.Write("Fly Car");
    }
}

```
