### What is Liskov Substitution Principle ?

1. The Liskov Substitution Principle (LSP) states that an object of a child class must be able to replace an object of the parent class without breaking the application.
2. Remember Child Class / Sub Class and Derived Class are Same things.
3. Remember Parent Class / Super Class and Base Class are Same things.


```csharp

// Base / Parent / Superclass

public class Employee
{
    public virtual int CalculateSalary()
    {
        return 100000;    
    }

    public virtual int CalculateBonus()
    {
        return 10000;
    }
}

```

```csharp

// Derived / Child / Subclass

public class PermanentEmployee : Employee
{
    public override int CalculateSalary()
    {
        return 200000;
    }
}
```

```csharp
public class ContractualEmployee : Employee
{
    public override int CalculateSalary()
    {
        return 150000;
    }

    public override int CalculateBonus(){
        throw new NotImplementedException();
    }
}

```

```csharp
static void Main(string[] args)
{
    Employee employee = new Employee();

    PermanentEmployee pEmployee = new PermanentEmployee();

    ContractualEmployee cEmployee = new ContractualEmployee();

    Console.WriteLine(employee.CalculateSalary());
    // 100000

    Console.WriteLine(employee.CalcuateBonus());
    // 10000

    // Follow Liskov Substitution Principle
    Console.WriteLine(pEmployee.CalculateSalary());
    // 200000

    Console.WriteLine(pEmployee.CalcuateBonus());
    // 10000

    Console.WriteLine(cEmployee.CalculateSalary());
    // 150000

    Console.WriteLine(cEmployee.CalcuateBonus());  // Break Code and hence Liskov Substitution Principle
    // Exception : The method or operation is not implemented
}

```

## All the base class methods must be applicable for the derived class.
