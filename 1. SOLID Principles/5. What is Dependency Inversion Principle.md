## What is Dependency Inversion Principle ? 

1. The Dependency Inversion Principle (DIP) states that a high-level class must not depend upon a lower level class.
2. Below example is of tight coupling and DataAccessLayer is dependent on FileLogger.

```csharp
public class DataAccessLayer
{
    public void AddCustomer(string name)
    {
        // add customer to the database
        FileLogger logger = new FileLogger();
        logger.Log("Customer added: " + name);
    }
}

```

To Solve this

```csharp
public interface ILogger
{
    void Log(string message);
}

public class FileLogger : ILogger
{
    public voide Log(string message)
    {
        // write message to a log file
    }
}

```

```csharp
public class DataAccessLayer
{
    private ILogger logger;

    public DataAccessLayer(ILogger logger){
        this.logger = logger;
    }

    public void AddCustomer(string name)
    {
        // add customer to the database
        logger.Log("Customer Added: " + name);
    }
}

```
